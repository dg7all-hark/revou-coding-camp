## 🐱 3D Cat — RevoU Coding Camp Sample

A simple single-page web app featuring an interactive **3D CSS cat**, built as a sample project for RevoU Coding Camp.

## 🚀 Live Demo

> Open `index.html` directly in your browser — no build step needed.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🖱️ **Mouse Tracking** | Cat rotates in 3D following your cursor (rotateX + rotateY) |
| 👀 **Blinking Eyes** | Auto blink animation every few seconds |
| 🐾 **Meow on Click** | Click the cat to trigger a "Meow! 🐾" speech bubble |
| 🎨 **Color Changer** | Cycle through 6 coat colors: orange, gray, yellow, purple, pink, green |
| 💃 **Wiggle Button** | Trigger a fun shake/wiggle animation |
| 🌊 **Float Animation** | Cat gently floats up and down with a pulsing shadow |
| 🐈 **CSS-only Cat** | Fully drawn with pure HTML + CSS — no canvas, no SVG, no images |

---

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **Tailwind CSS** (via CDN) — utility-first styling & layout
- **Vanilla JavaScript** — all interactions, no frameworks

## 🏃 How to Run

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Move your mouse and interact with the cat!

```bash
git clone https://github.com/dg7all-hark/revou-coding-camp.git
cd revou-coding-camp
# then open index.html in your browser
```
